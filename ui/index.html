    Use gamepad input
    Steam Deck trackpads & back paddles
    Launch this app from Steam and select Gamepad with Mouse Trackpad. Edit this app’s layout:
    • Right trackpad: As Mouse; click: Left Mouse Click.
    • Left trackpad: Scroll Wheel; click: Right Mouse Click.
    • Both sticks: Joystick. Triggers, bumpers, D-pad and face buttons: their normal Gamepad outputs.
    • Turn on the back grips and bind L4, R4, L5 and R5 to buttons the robot reads, like A, B, X and Y. Extra buttons show up under Inputs only if the controller’s driver reports them.
    You set this up once and Steam keeps it. In desktop mode the triggers can act as mouse clicks, so start Torque from Steam to get its own layout. The trackpads work on Torque and on the robot’s page.
    What each control does is up to the robot’s code. While this test is open, the robot sees the controller at rest.
