Torque V2.15 is available for Windows x64 and Apple Silicon Macs. Steam Deck/Linux stays on V2.1 for now.

- **A cleaner, more consistent app:** every tab shares one set of button heights, title sizes, section labels, scrollbars and dialog layouts, in dark and light, and Setup, Calibrate, Simulate and Settings fit a 1280 × 718 laptop window without cutting anything off.
- **One robot, three steps:** Setup describes the robot, Calibrate measures the real one, and Simulate holds its routes. Each robot keeps several routes, each with its own field and export.
- **Routes run on physics:** pins can go anywhere. A path that runs into something glows yellow and Run drives it anyway, so you can watch what the robot hits; exports wait until every path is clear.
- **SWYFT Programmer (Windows):** set up SWYFT servos with Simple and Advanced settings, next to the Axon Programmer in Calibrate.
- **Servo Test:** move a servo on any Control Hub or Expansion Hub port over USB with a live slider and Low/Mid/High presets, with the pulse and battery read back from the hub.
- **Calibrate:** Electronics, Mechanisms, Camera and a Real run report, with Live debug that remembers which encoders and Pinpoint it saw.
