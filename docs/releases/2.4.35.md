Torque V2 for Windows, Apple Silicon Macs and Steam Deck. Download one file:

- **Windows:** `DeckDriverStation-2.4.35-Windows-Setup.exe`
- **Mac (Apple Silicon):** `DeckDriverStation-2.4.35-macOS-arm64.zip`
- **Steam Deck / Linux:** `DeckDriverStation-2.4.35-SteamDeck.run`

- **Updates in the app on every system:** the update icon beside the bug report turns yellow when a new version is out (green when you're up to date; hover to see your version). Click it, then **Download and install**: Windows, Mac and Steam Deck update from these same downloads and restart Torque. Main or Testing is chosen in the same window. Copies of 2.4.34 on Windows and Steam Deck need this version downloaded once by hand; Macs on 2.4.34 update in the app.
- **The Mac app is Torque:** it is named Torque in the Dock, menu bar and Finder, and installs as `Torque.app`.
- **Starter Mecanum is the demo:** a first run opens the Starter Mecanum demo; the Test setup and the A301 Swerve demo are gone.
- **The 3D field fits the window:** the camera frames the whole field, walls included, for any window shape, and refits when the window changes size.
- **Setup files move a robot between computers:** Save file carries the robot's CAD, joints, mechanisms, wiring, calibration, every path and the device calibration, so Open file on another computer shows it exactly as saved.
