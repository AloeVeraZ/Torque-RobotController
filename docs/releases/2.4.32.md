Torque V2.1 is available for Windows x64, Steam Deck/Linux x64, and Apple Silicon Macs.

- **Setup and calibration:** USB setup comes first, Debug is one step, and camera calibration is part of the same flow.
- **Kiwi Swerve:** Calibrate and tune each steering pod with oscillation checks, then generate an FTC TeleOp from the calibrated chassis. The IMU heading check accepts a turn in either direction.
- **Axon on Windows:** Use both programmer generations at once. Torque identifies servos where the hardware allows and prompts for the model or mode when needed.
