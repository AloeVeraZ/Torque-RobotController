Torque V2 for Windows, Apple Silicon Macs and Steam Deck. Download one file:

- **Windows:** `DeckDriverStation-2.4.34-Windows-Setup.exe`
- **Mac (Apple Silicon):** `DeckDriverStation-2.4.34-macOS-arm64.zip`
- **Steam Deck / Linux:** `DeckDriverStation-2.4.34-SteamDeck.run`

- **Setup files move a robot between computers:** Save file now always carries the robot's CAD (an imported STEP or mesh, or the kit chassis), its joints, mechanisms, wiring, calibration, every path and the device calibration (camera settings and device checks). Open file on another computer, Windows, Mac or Steam Deck, shows the robot exactly as it was saved, instead of a plain rectangle.
- **Steam Deck is back:** this release is built for all three platforms.
- **One download per platform:** each release now has a single file for each device. Windows and Steam Deck install new versions from this page; Macs still update in the app.
