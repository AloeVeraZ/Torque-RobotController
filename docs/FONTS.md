# Bundled fonts

Inter (`ui/fonts/inter-latin.woff2`) and Barlow Condensed Bold
(`ui/fonts/barlow-condensed-700-latin.woff2`) are shared with the owner's
MotionModule design. OpenDyslexic Regular and Bold (`ui/fonts/opendyslexic-regular.woff2`
and `ui/fonts/opendyslexic-bold.woff2`, by Abbie Gonzalez, from
[antijingoist/opendyslexic](https://github.com/antijingoist/opendyslexic)) is the font for
readers with dyslexia in Settings → Text. It ships unmodified, so it keeps its reserved name.
All of them are bundled for offline use on robot Wi-Fi networks.

The SIL Open Font License notices are distributed with the app:

- [Inter license](../ui/fonts/OFL-Inter.txt)
- [Barlow Condensed license](../ui/fonts/OFL-BarlowCondensed.txt)
- [OpenDyslexic license](../ui/fonts/OFL-OpenDyslexic.txt)

The controller drawing is original SVG arranged to match the standard control
layout on Hardware Tester. The app does not embed that website or its scripts.
